# iDeCo＋みらいナビ 加入者版 変更履歴

画面の改訂と計算方法の改訂を分けて記録します。

## 画面版 v1.2.0／計算版 v26（2026-07-27）

- 入力した希望月額を「取崩開始時の将来の額面」と明記
- 取崩開始後は、物価上昇率に合わせて月額を毎年増やす計算へ変更
- 物価上昇率を変えると、資産寿命、残高がもった割合、開始時月額の目安も再計算
- 相談メモへ `spendMode: "keep"` を含む再現コード `MN3` を出力
- 表示文、グラフ説明、相談メモを同じ意味へ統一
- 「将来の額面は変わらない」という旧説明を削除し、物価上昇率で取崩額、将来残高、資産寿命も変わる説明へ修正
- GitHubのpush／PR検査へ、生成物一致、再現契約、明示計算、50,000件fuzzを追加

固定番号（seed `19670701`）と乱数列は変更していません。旧 `MN2` は額面固定、現行 `MN3` は物価連動です。意味を混ぜないため、計算版を `v26` に更新しました。

改訂前の基準コミット：`d5f283caf876d174a7a1ca893f91746cf3c26c06`

### 公開順

1. アドバイザー版 `MN3`／`v26` を先にmerge・deploy
2. 本番アドバイザー版で旧 `MN1`／`MN2` を額面固定のまま再現確認
3. 加入者版 v1.2.0／`MN3`／`v26` をmerge・deploy
4. 本番加入者版で発行した `MN3` を、本番アドバイザー版で10項目照合
5. CSV、印刷、物価連動表示を本番確認

## 画面版 v1.1.0（2026-07-27）

利用者の試用意見を反映した版です。

- 正式名称は「iDeCo＋みらいナビ」のまま維持し、企業型DCにも使えることを副題で明記
- 「積立シミュレーション」「積立から取り崩しまでの見通し」など、操作の流れが伝わる案内へ変更
- 年齢、毎月の掛金、取り崩し開始年齢、希望月額を、スライダーと数字入力のどちらでも変更可能にした
- 条件変更中は自動計算せず、「この条件で計算する」を押したときだけ計算する方式を維持
- 希望月額で資産が何歳ごろまで持つかを、2,000通りの小さいほうから40%の位置として追加
- 再現コードを `MN2` へ更新し、資産が持つ年齢もアドバイザー版との一致確認対象に追加
- 画面と相談メモへ、画面版・計算版・更新日を表示
- 計算後も結果見出しに「未計算」が残る表示矛盾を修正

計算式と固定シードは変更していません。計算版は `v25` のままです。表示結果の照合項目を9項目から10項目へ増やしたため、再現コードは `MN1` から `MN2` へ更新しました。

### 公開順

1. `MN1` と `MN2` の両方を読めるアドバイザー版を先に公開
2. 本番アドバイザー版で旧 `MN1` と新 `MN2` の再現を確認
3. その後に加入者版 v1.1.0を公開
4. 本番加入者版で発行した `MN2` を、本番アドバイザー版で10項目照合
